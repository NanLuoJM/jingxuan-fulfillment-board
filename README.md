# 鲸选数字云仓履约看板

即时零售前置仓的仓内生产大屏：一屏看清订单、拣货、复核、配送、人员五个环节的进度，四个环节的超时预警，收货上架进度，人效排名和履约质量。

- 单个 HTML 文件，无外部依赖，断网可用
- 按 1920×1080 设计，任意屏幕等比缩放
- 当前为模拟数据演示版

## 打开

下载 `index.html`，用浏览器直接打开，按 F11 全屏。

演示强度切换：键盘 `1` 平稳、`2` 繁忙、`3` 爆单；或在网址后加 `?demo=calm`、`?demo=busy`、`?demo=storm`。

## 看板内容

| 区域 | 内容 |
| --- | --- |
| 顶部五个容器 | 订单情况、拣货情况、复核情况、配送情况、人员情况；待拣货超过在线人数时，拣货情况整格变红 |
| 订单趋势图 | 0–23 时每小时单量：今日实际、今日预约、昨日对照 |
| 超时订单（四张卡） | 待领取 → 待拣货 → 待复核 → 待取货；左栏显示超时预警单数，右栏列出已超时订单 |
| 待收货上架余量 | 标件（按件）与计重（按 KG）的收货完成率、上架完成率 |
| 人效排名 | 按订单人效排 TOP 8，附个人履约率 |
| 履约质量 | 核心指标订单履约率，以及仓内履约率、配送准时率、退款率、绝望订单数 |

超时标准、预警提前量、达标分档等全部取值与计算口径见 [AGENTS.md](AGENTS.md)。

## 接入真实数据

只需改写 `index.html` 中的 `DataSource.fetch()`，返回同样结构的数据即可；预警与超时等级由页面按固定阈值自行计算。
